# macOS 版本使用说明

这个文件夹是给 Mac 使用的版本。它使用 Python 3 和 Tk 图形界面，能实现和 Windows 版一样的功能：

- 输入自己的校园网账号、密码并保存
- 修改自动断网前的超时时间
- 一键联网、一键断网
- 启动/停止自动模式
- 查看当前在线状态
- 贴边隐藏到屏幕边缘（鼠标移到右侧小标签即可弹出）

## 第一次使用

1. 确认 Mac 已经安装 Python 3。可以从 <https://www.python.org/downloads/> 下载安装。
2. 打开“终端”，进入这个文件夹。
3. 执行一次：

```bash
chmod +x 启动.command
```

4. 双击 `启动.command` 即可打开界面。

如果系统提示无法打开，可以在 `启动.command` 上点右键，选择“打开”，然后再次点“打开”。

## 如果双击后提示缺少 tkinter

如果 Python 是用 Homebrew 安装的，需要额外安装 Tk：

```bash
brew install python-tk
```

安装完成后重新双击 `启动.command`。

## 账号设置

打开界面后，在“账号与超时设置”中填写：

- 账号：自己的校园网账号
- 密码：自己的校园网密码
- 超时时间：超过这个时间没有操作键盘或鼠标，就自动断网

点“保存设置”即可保存；点“保存并登录”会保存后立即联网。

账号密码保存在本文件夹的 `config.json` 中，请勿把这个文件发给别人。
